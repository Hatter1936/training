## 1. Общие соглашения (Строго)

- **Формат данных:** JSON (`Content-Type: application/json`).
- **Кодировка:** UTF-8.
- **Даты и время:** например: `2026-10-22T18:30:00` - так правильно.
- **Булевы значения:** `true` / `false` (без кавычек).
- **Пустые значения:** Если поле необязательное, передаем `null` или не передаем ключ вообще (оговаривается отдельно).
- **Авторизация:** [Указать, нужна ли. Если да, то как передается токен: `Authorization: Bearer <token>`].

### 2. Единый формат ошибок
Если бэкенд возвращает ошибку (400, 404, 500), она всегда приходит в таком виде:
```json
{
  "code": "ERROR_CODE",
  "message": "Понятное описание ошибки для пользователя",
  "timestamp": "2026-10-22T18:30:00"
}
```

## Коды ответов:

- `200 OK` — Успешный GET, PATCH.
- `201 Created` — Успешный POST (создание).
- `204 No Content` — Успешный DELETE.
- `400 Bad Request` — Ошибка валидации (фронт прислал кривые данные).
- `404 Not Found` — Сущность не найдена (например, неверный ID).

## 4. Эндпоинты (Ресурсы)
**[Название сущности]** (например, Tasks, Orders, Rooms)

### 1. Получить все записи
**Метод:** `GET /items`

**Параметры (Query):**

- `?status=NEW` (опционально, для фильтрации)

**Ответ (200 OK):** Массив объектов.

```json
[
  { "id": 1, "name": "Пример", "status": "NEW" },
  { "id": 2, "name": "Пример 2", "status": "DONE" }
]
```

### 2. Получить одну запись по ID
**Метод:** `GET /items/{id}`

**Ответ (200 OK):** Объект.

```json
{ 
    "id": 1, 
    "name": "Пример", 
    "status": "NEW" 
}
```

**Ошибки:** `404 Not Found` (если такого ID нет).

### 3. Создать запись
**Метод:** `POST /items`

**Тело запроса:**

```json
{
  "name": "Строка (обязательно)",
  "description": "Строка (опционально)"
}
```

**Ответ (201 Created):** Созданный объект с присвоенным id.

```json
{ 
    "id": 1, "name": "Строка", 
    "description": "Строка", 
    "createdAt": "2026-10-22T18:30:00" 
}
```

**Ошибки:** `400 Bad Request` (если `name` пустой).

**Пример для фронта (JS):**

```javascript
fetch('http://localhost:8080/api/items', {
  method: 'POST',
  headers: { 
    'Content-Type': 'application/json' 
    },
  body: JSON.stringify({ 
    name: 'Моя запись', description: 'Тест' 
    })
})
.then(res => res.json())
.then(data => console.log(data))
.catch(err => console.error(err));
```

### 4. Обновить запись (частично)
**Метод:** `PATCH /items/{id}`

**Тело запроса:** (передаем только те поля, которые меняем)

```json
{ 
    "status": "DONE" 
}
```

**Ответ (200 OK):** Обновленный объект.

**Ошибки:** `404 Not Found`, `400 Bad Request`.

### 5. Удалить запись
**Метод:** `DELETE /items/{id}`

**Ответ (204 No Content):** Пустое тело.

**Ошибки:** `404 Not Found`.
